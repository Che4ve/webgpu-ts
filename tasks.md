Я убрал все типы данных из линейки в veekay/types.hpp. Теперь у них есть более удобный API. veekay::vec2, veekay::vec3, veekay::vec4, veekay::mat4 специально повторяют функионал GLSL, а также у них есть удобные перегрузки операторов!

Теперь функция initialize принимает один аргумент:
initialize(VkCommandBuffer cmd) {}

Нам потом этот функционал пригодится для загрузки текстур для следующей лабы

Чтобы работать с клавой и мышой, есть новый API veekay/input.hpp
veekay::input::mouse содержит функции для работы с мышью. Вам понадобятся функции cursorDelta, чтобы отслеживать дельту сдвига мыши для поворота камеры, а также isButtonDown, isButtonPressed для нажатий по кнопкам

veekay::input::keyboard содержит функции для работы с клавиатурой: isKeyDown и isKeyPressed ваши друзья, чтобы перемещать камеру с помощью клавиш
